# run-logger
RunLogger is an Android fitness tracking application which supports manual input, GPS-based tracking, and automatic activity recognition. The app allows users to record, view, and manage their physical activities while maintaining a personal profile and preferences.

# Features
- User profile management
- Multiple workout input modes: Manual, GPS, and Automatic
- Persistent storage using a local database
- Workout history browsing and deletion
- Real-time GPS tracking and map visualization
- Activity recognition using accelerometer data
- Settings for privacy, units, and comments
